\# Maseerak Windows Installer



Official Windows installer for Maseerak GPS Tracking System.



\## Installer



File:



maseerak-setup-1.0.0.exe



\## Installation



1\. Download the installer.

2\. Run the setup file.

3\. Follow the installation wizard.

4\. Start Maseerak GPS Tracking Server.



\## Version



Version: 1.0.0



\## Platform



Windows 10 / Windows 11
